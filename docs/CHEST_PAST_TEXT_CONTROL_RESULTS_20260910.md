Thus the model can render the broad state under a changed current condition;
the KV-only negative is not evidence that open geometry is intrinsically
unrenderable. This is NOT faithful recovery of the same source configuration,
nor an autonomous state detector or a matched-original-prompt memory victory.
Inspection is descriptive interval-board review, not continuous every-frame
playback or blind human evaluation. Neither new phrasing nor new seeds are tried.

Next discriminating mechanism, if pursued, is whether a suitable current state
condition lets archived KV preserve unprompted source details and suppress new
actions, beyond this zero-extra-KV text control. It needs a new registration and
equal-condition comparisons; do not erase the existing KV-only negative.
